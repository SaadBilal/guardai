Guard AI Proxy API Reference

Guard AI Proxy operates as a developer-first reverse proxy designed to sit between application frontends and frontier LLM backends (OpenAI, Anthropic, Vector DBs). It guarantees zero data exposure through in-memory PII scrubbing, context-level multi-tenant vector isolation, and cryptographic audit hashing under EU AI Act Article 12.

Production Gateway Endpoint https://saadbilal.github.io/guardai/v1
● Operational (Latency <15ms)

Headers & Multi-Tenant Context

Every request sent through Guard AI requires standard authentication headers along with a mandatory X-Tenant-ID header. This ID enforces strict multi-tenant context boundary constraints across downstream LLMs and Vector Search queries.

Header Name Type Required Description
X-Tenant-ID String Yes Unique tenant identifier used for isolation context & audit logging.
Authorization String Optional Upstream LLM Bearer token (Passed transparently to OpenAI/Claude).
Content-Type String Yes Must be set to application/json.

SDK & Client Integration Snippets

Integrate Guard AI Proxy into existing applications by simply changing the base URL. No deep code refactoring required. 

import requests

url = "https://saadbilal.github.io/guardai/v1/chat/completions"
headers = {
    "Content-Type": "application/json",
    "X-Tenant-ID": "tenant-saad-corp"
}
payload = {
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Contact Saad Bilal at saad.bilal@enterprise.com"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
curl -X POST "https://saadbilal.github.io/guardai/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: tenant-saad-corp" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Contact Saad Bilal at saad.bilal@enterprise.com"}]
  }'
const fetch = require('node-fetch');

async function runProxy() {
  const response = await fetch('https://saadbilal.github.io/guardai/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'tenant-saad-corp'
    },
    body: JSON.stringify({
      model: 'gpt-4o',
      messages: [{ role: 'user', content: 'Contact Saad Bilal at saad.bilal@enterprise.com' }]
    })
  });
  const data = await response.json();
  console.log(data);
}
runProxy();
